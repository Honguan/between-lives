# 萬象之間 · BETWEEN LIVES

[直接遊玩](https://between-lives-honguan.zippy-goose-5321.chatgpt.site) · [公開原始碼](https://github.com/Honguan/between-lives)

選一個世界、一種物種或形態，看它自動走完一生。主角可以是動物、菌絲網絡、天體、數位生命，也可以是一個承諾。支援手機、桌面、繁體中文與 English。

## 怎麼玩

1. 選擇世界與物種／形態，按「開始這一生」。
2. 系統分配兩份天賦。角色依天生傾向、當前能力與機率自行行動；存在偏低時，較傾向保全自己。
3. 每章顯示事件、角色的行動、結果與能力變化。玩家不分配天賦、不選事件行動，也不手動指定結局。
4. 一世通常最多 24 章，特定天賦延長至 29 章；存在歸零也會結束。結局留下的遺物為下一世增加一項能力。

可暫停閱讀，或調整每章停留 6、12、24 秒。空白鍵可暫停／繼續。展開先前經歷、開啟對話框、離開遊玩頁或切到背景分頁，都會暫停播放。閱讀速度與語言不改變模擬結果。

第 7、21 章可能蛻變或跨越世界，第 14 章可能改寫法則。先前行動留下的因果可能在數章後回來。這些經歷都由系統決定。

## 內容

- 60 種形態、6 個存在類別、16 個世界、12 條有數值效果的法則、18 份天賦。
- 40 個基礎事件、8 條因果回訪線、蛻變與法則事件。
- 8 個程序情節結構、32 件有用途與代價的奇物、16 種環境條件。每次排除角色自身作為來客，共有 8 × 32 × 59 × 16 = 241,664 種組合。這是組合數，不是獨立手寫故事數。
- 12 種結局，依存活狀況、能力、蛻變、回訪與復甦等經歷判定。
- 前世遺物繼承、10 個成就、形態圖鑑、最近 120 世完整紀錄。
- JSON 存檔匯入／匯出、依顯示語言匯出故事、可關閉的合成環境音、原創 Canvas 星圖。

故事使用有限的手寫材料與程序組合，可以一直輪迴，沒有即時 AI 敘事服務。相同版本、種子、起始世界與形態、前世遺物會產生相同的自動經歷。種子由系統產生，不是玩家選項。

繁體中文與 English 都涵蓋介面、世界、角色、事件、結果與結局。語言切換只改顯示；新紀錄同時保存兩種敘事。舊版存檔仍可載入，缺少英文的歷史紀錄保留原文並加註說明。舊版尚未完成的人生會從原進度繼續自動模擬。

## 本機執行

需要 Node.js 22 或以上；無第三方依賴，不需要安裝套件。

```sh
npm start
# http://127.0.0.1:4173

npm test
npm run build
```

建置使用系統的 tar，將靜態資產與 Sites manifest 打包到 .artifacts/site.tar.gz。產物不納入 Git。

## 原始碼

| 檔案 | 用途 |
| --- | --- |
| public/content.js | 形態、世界、法則、天賦與成就 |
| public/events.js | 基礎事件、行動效果與因果回訪 |
| public/fragments.js | 用途與代價一致的程序故事組合 |
| public/english.js | 英文內容；不操作遊戲狀態或亂數 |
| public/engine.js | 自動行動、可重現亂數、結局、存檔驗證 |
| public/app.js | 雙語介面、播放控制、本機儲存、音效與星圖 |
| public/style.css | 手機與桌面排版 |
| tests/engine.test.mjs | 17 項檢查，含 6,000 世自動模擬與 2,400 世事件驗證 |

新增內容使用穩定 ID，補齊雙語文字與測試。事件的行動效果由引擎保留，玩家不能從介面直接呼叫選項。不要把可執行的事件定義放進存檔。更改亂數呼叫順序或內容清單會改變種子的後續經歷；跨版本若需要精確重播，必須另外版本化生成規則。

## 存檔與隱私

進度只存於目前瀏覽器的 localStorage，鍵為 between-lives.v1；語言偏好另存於 between-lives.language。沒有帳號、雲端同步、廣告或分析追蹤，不載入外部字型。Sites 代管層可能加入安全檢查腳本。

換裝置或清除網站資料前，請在設定匯出存檔。匯出提供檔案下載與全文複製；下載受限制時，可保存全文，再於匯入視窗貼上。匯入先驗證，再確認取代。無法讀取的舊資料會被保留，自動覆寫會暫停。最近 120 世以外的完整故事不會繼續保留；總世數、圖鑑與成就仍累積。
