# 萬象之間 · BETWEEN LIVES

**下一生，不必是人。**

一款繁體中文、可在手機與桌面遊玩的程序敘事輪迴模擬遊戲。成為深海鯨、菌絲網絡、流浪行星、被刪除的檔案，或一句未說出口的話。

**[開始遊玩](https://between-lives-honguan.zippy-goose-5321.chatgpt.site)**

## 怎麼玩

1. 選擇初始形態，從五個候選中帶走兩份天賦。也可以為形態取一個自己的名字。
2. 在每個生命片段中選擇行動。感知、共鳴與偏離影響成功率；存在會隨時間流逝。
3. 種下的因果可能在 3–5 章後回來。第 7、21 章可以蛻變或穿越世界；第 14 章有機會改寫宇宙法則。
4. 每世通常 24 章，特殊天賦可延長至 29 章。存在歸零也會結束這一世。留下遺物，繼承給下一世，再出發。

命運模式強調取捨；漫遊模式降低消耗、提高成功率。鍵盤 `1` / `2` / `3` 選擇，`Enter` 繼續。

## 宇宙裡有什麼

- 48 種形態、6 個存在類別、12 個世界、12 條有實際效果的法則、18 份天賦。
- 40 個手寫基礎事件、8 條因果回訪線，以及蛻變／改寫法則事件。
- 程序異常事件：6 個情節結構 × 24 件帶有用途與代價的奇物 × 48 種來客 × 12 種情境，再依所在地與角色能力變化。每次排除自己作為來客，共 81,216 種異常事件組合；這是組合數，**不代表同等數量的獨立手寫故事**。
- 7 種結局，包括須同時累積理解、連結、偏離與因果回訪的隱藏結局。
- 輪迴繼承、10 個成就、形態圖鑑、最近 120 世完整手記、存檔匯入／匯出、純文字人生故事匯出、世界種子分享。
- 原創 Canvas 星塵軌道圖、可關閉的合成環境音、手機排版、鍵盤操作與減少動畫支援。

可以一直輪迴；內容來自有限的手寫材料與程序組合，**不是字面上的無限故事，也沒有即時 AI 敘事服務**。相同種子、起始選項、前世遺物與行動序列會重現相同經歷。分享種子會分享世界與天賦起點；各玩家自己的前世遺物仍有影響。

## 本機執行

需要 Node.js 22 或以上；無第三方依賴，不需要 `npm install`。

```sh
npm start
# 開啟 http://127.0.0.1:4173

npm test
npm run build
```

`npm run build` 使用系統的 `tar`，把靜態資產與 Sites manifest 打包到 `.artifacts/site.tar.gz`。Windows、macOS 或 Linux 均可；`.artifacts` 不納入 Git。

## 原始碼

| 檔案 | 用途 |
| --- | --- |
| `public/content.js` | 形態、世界、法則、天賦與成就 |
| `public/events.js` | 手寫事件、抉擇與因果回訪 |
| `public/fragments.js` | 帶有一致用途與代價的程序事件組合 |
| `public/engine.js` | 可重現亂數、遊戲狀態、機率、結局與存檔驗證 |
| `public/app.js` | 畫面、互動、本機儲存、音效與星圖 |
| `public/style.css` | 桌面／手機與無障礙樣式 |
| `tests/engine.test.mjs` | 模擬、重現性、匯入安全與輪迴檢查 |

新增形態與事件時，使用穩定且唯一的 ID；事件以 `group` 決定適用類別。選項可改變數值，並可留下 `chain`、發生 `shift`、`warp` 或 `rewrite`。不要將可執行事件定義放入玩家存檔。調整亂數呼叫順序或事件清單會改變既有種子的未來，正式版本若需保留舊種子重播，應明確版本化生成規則。

## 存檔與隱私

進度只放在目前瀏覽器的 `localStorage`，鍵為 `between-lives.v1`。無帳號、雲端同步、分析追蹤、外部字型或第三方腳本。環境音僅在使用者開啟後播放。

清除網站資料、私人瀏覽結束或換裝置都可能失去本機進度，請使用設定中的「匯出完整存檔」。匯入先驗證，再要求確認替換；無法讀取的舊存檔不會被靜默覆寫。完整手記保留最近 120 世，總輪迴數、圖鑑與成就繼續累積。儲存空間不足會提示匯出備份。

## 發佈

這個專案部署在 OpenAI Sites。`.openai/hosting.json` 的 `project_id` 是本站的公開識別資料，不是憑證。Fork 後若要建立自己的 Sites 專案，移除該識別欄位，再使用自己的 Sites 專案；不要對原專案部署。

每次發佈先完成 `npm test`，提交並推送完全相同的來源狀態，再從該提交打包靜態檔案、儲存 Sites 版本並部署。網站不依賴 Sites 專屬 API，也可以直接放到任何靜態網站主機。
